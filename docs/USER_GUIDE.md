# 化安智控使用说明与数据来源

文档版本：0.2.0
内置数据版本：2026-07-13

## 1. 系统用途与安全边界

“化安智控”用于化工安全知识查询、教学演示、设备巡检记录、事故响应辅助研判、清洁生产初步评价和 PID 温控原理仿真。

本系统不能替代以下文件或专业判断：

- 化学品供应商最新版 SDS；
- 企业操作规程、作业许可、联锁逻辑和设备说明书；
- 企业经评审备案的应急预案及现场指挥；
- 压力容器、锅炉、压力管道和安全附件的法定检验；
- 适用行业的清洁生产评价指标体系；
- 真实反应釜的控制器设计、整定和安全保护系统。

发生真实事故时，应优先报警、撤离和服从现场指挥。未知物质、未知浓度或缺氧环境按最高风险处理，未经训练的人员不得进入危险区域实施堵漏或救援。

## 2. 启动与安装

### 2.1 Android 手机

1. 将 APK 发送或复制到手机。
2. 在系统文件管理器中打开 APK；如系统提示，请仅为当前文件管理器临时允许“安装未知应用”。
3. 安装后打开“化安智控”。同一签名的较新版本可覆盖安装，设备中的本地收藏和巡检记录通常会保留。
4. 报告导出时，根据系统提示选择保存位置；打印报告时可在 Android 打印界面选择“另存为 PDF”。

当前仓库脚本生成的是调试签名 APK，仅用于测试和演示，不适合作为应用商店正式安装包。

### 2.2 Web 版本

开发环境需要 Node.js 22.13 或更高版本：

```bash
npm ci
npm run dev
```

打开终端显示的地址即可使用。生产构建运行 `npm run build`，完整检查运行 `npm test`。

## 3. 导航与通用操作

- 桌面端通过左侧导航栏切换模块。
- 手机端通过底部导航栏进入首页、化学品、巡检、应急、清洁生产和仿真模块。
- 页面刷新后，系统会根据 URL Hash 返回最近打开的模块。
- 收藏、最近查询和巡检记录保存在当前浏览器或手机应用的本机存储中，不会自动上传服务器。

## 4. 各模块使用方法

### 4.1 首页工作台

首页展示五个核心模块入口、内置知识库数量、最近查询和风险提示。

使用方法：

1. 点击任务卡进入对应模块。
2. “最近查询”来自当前设备的本机历史记录。
3. 数据库数量由应用内置 JSON 数据实时统计，不是联网查询结果。

数据来源：化学品、设备、事故数量分别取自三份 Excel 转换后的内置知识库；最近查询和巡检信息来自用户本机 `localStorage`。

### 4.2 化学品安全查询

1. 在查询框输入中文名、英文名、CAS 号、分子式或危险关键词。提示内容较长时会自动滚动。
2. 可选择易燃、有毒、腐蚀、氧化、爆炸等筛选条件。
3. 点击化学品卡片查看理化性质、危险性、毒性、防护、储存、泄漏处置、灭火和禁忌物信息。
4. 可收藏化学品、生成文本安全卡，或选择两种物质进行对比。
5. 发生事故时可从化学品详情跳转到应急指导模块。

数据说明：

- 名称、CAS、分子式、理化性质、危险性、毒性、防护和处置字段直接来自化学品 Excel。
- 页面风险颜色由程序根据“危险类别”和“毒性”中的关键词分为低、中、高和重大风险，属于检索辅助标签，不等同于 GHS 法定分类。
- “易燃、有毒、腐蚀”等标签也由程序关键词匹配生成。
- 两种物质的相容性提示根据 Excel 中的禁忌物字段进行文本匹配，只用于提醒复核，不能替代相容性试验或专业评估。

实际使用时，应再次核对具体供应商最新版 SDS。混合物、不同浓度溶液以及不同纯度产品的闪点、爆炸极限、毒性和储存要求可能明显不同。

### 4.3 设备安全检查与风险评估

手机端分为三个界面：

1. **选择设备**：从 18 类常用化工设备中选择设备类型。
2. **设备信息**：填写设备位号和检查人员，确认检查项目数量。
3. **分步检查**：逐项查看检查方法和正常判定标准，选择“正常、异常、不适用、待复核”，填写实测值和现场备注。

检查过程中：

- 每一项会显示与当前项目对应的实测值示例；长示例会滚动显示。
- 选择“异常”时，系统展示可能后果和建议措施。
- 风险得分和等级随结果即时更新。
- 全部项目完成后，可提交巡检报告、打印/保存 PDF，或导出 Excel 兼容 CSV。

数据说明：

- 设备名称、检查项目、方法、正常标准、可能后果、建议措施、周期和岗位来自设备巡检 Excel。
- 实测值示例为项目内根据检查项语义补充的填写示例，不是现场标准值。
- 风险权重由程序根据“爆炸、飞温、超压、联锁失效、泄漏、中毒”等关键词生成 1、2、3、5 级权重。
- 风险得分、异常数量修正系数和低/一般/较高/重大风险阈值为本项目原型算法，不是法定风险分级标准。
- 设备位号、检查人员、现场判断、实测值和备注均由使用者填写，并保存在当前设备本机。

设备的真实温度、压力、液位、转速、振动和氧含量安全范围，必须以设计文件、设备说明书、工艺安全分析和企业批准规程为准。

### 4.4 事故应急处置指导

应急模块分为三个界面：

1. **选择事故**：按事故名称、类别或典型征兆搜索并确认事故类型。
2. **响应建议**：查看典型征兆、主要风险和首要动作，并根据事故规模、人员受伤和厂外影响研判蓝、黄、橙、红响应建议。
3. **应急流程**：二次确认后，按“报警撤离、切断停车、警戒检测、专业控制、救护与环境、监测恢复”六个阶段执行和记录。

每一步同时显示禁止操作、所需防护、升级条件和恢复条件。普通人员仅执行报警、撤离、提醒、人员清点以及可从安全位置完成的远程停机或关阀。

数据说明：

- 事故类型、征兆、风险、基础响应建议、六步处置、禁止操作、PPE、升级和恢复条件来自事故应急 Excel。
- 蓝、黄、橙、红四级组织响应措施来自同一 Excel 的“响应分级措施”工作表。
- 页面根据基础等级、事故规模、人员受伤和厂外影响取较高响应等级，此规则属于系统辅助研判。
- 实际企业响应级别、启动条件、指挥权限和报告程序必须以企业预案和属地规定为准。

### 4.5 清洁生产与能耗排放评价

本模块分为两个界面：

1. **生产过程数据**：填写产品产量、原料投入、水、电、蒸汽、天然气、燃料、废水、废气、固废、副产物回收、批次和运行时间。
2. **综合评分**：查看单位产品指标、六维得分、综合等级和改进建议，可返回修改或打印评价报告。

数据说明：

- 所有生产数据均为用户输入，系统没有连接真实工厂、仪表、DCS 或能源管理系统。
- 单耗、利用率、收率和回收率由页面公式实时计算。
- 电力、蒸汽、天然气和燃料折标系数，以及能源 25%、水资源 20%、原料利用 20%、废水 15%、废气 10%、固废与回收 10% 的权重，均为本项目演示参数。
- 目标值、一级至四级评分和动态建议为原型算法生成，不直接来源于三份 Excel，也不代表任何行业的正式清洁生产审核结论。

正式评价时，应替换为企业所在行业适用的国家或地方清洁生产评价指标体系、能源计量口径和最新折标系数。

### 4.6 反应釜温度智能控制仿真

本模块分为三个界面：

1. **模型参数**：填写初始温度、目标温度、环境温度、物料质量、比热、最大加热/冷却能力、仿真时间、步长、PID 参数、反应放热、散热和报警温度。
2. **仿真曲线**：运行仿真并查看温度、偏差、加热功率、冷却阀门和温度变化速率。
3. **结果评价**：查看最大温度、超调、稳态误差、调节时间、稳定性和参数建议，可导出 CSV 数据。

数据说明：

- 初始默认参数是程序内置的教学示例，不来自真实反应釜或历史生产数据。
- 温度曲线由离散能量平衡和 PID 公式计算，包含简化的加热、冷却、线性散热和指数衰减反应放热模型。
- 评价结果由仿真序列计算生成，不是仪表测量值。
- 模型没有覆盖反应动力学、相变、传热面积变化、阀门非线性、测量滞后、联锁可靠性和设备极限，因此不能用于真实控制器整定或安全联锁设计。

## 7. 本机数据、导出与隐私

- 收藏、最近查询和巡检历史保存在当前设备，不会自动同步到其他手机或浏览器。
- 清除应用数据、卸载应用或清除浏览器站点数据可能删除本机记录。
- CSV 导出内容包含设备、人员、时间、检查结果、实测值和备注，分享前应检查是否含个人信息或企业敏感信息。
- PDF 打印内容以当前页面为准；Android 中可通过系统打印服务保存为 PDF。
- 当前版本不采集账号、定位、通讯录、相机、麦克风或后台遥测数据。

## 8. 常见问题

### 查询不到某种化学品

尝试中文名、英文名、CAS 号、PubChem CID 或分子式。当前离线库为 1500 种化学品：前 100 条含整理后的安全信息，随后 900 条提供基础属性，最后 500 条均具有唯一有效 CAS，并完整收录 PubChem 实验外观、熔点、沸点、密度和溶解性；闪点、蒸气压、折射率及黏度按来源实际收录。实验值可能因纯度、压力和测定方法而不同，应用会并列保留来源值；危险性仍须以具体产品 SDS 为准。

后 1400 条已进一步进行 GHS 来源核验：713 条命中监管或权威来源，4 条只有普通来源，683 条未找到公开 GHS 分类。可使用“GHS已核验”筛选查看前一类记录。详情页的“数据核验与来源”会显示来源数量、来源名称、一致 H 代码及核验日期。“来源已核验”只表示分类记录可追溯，不代表对特定供应商、浓度或混合物完成 SDS 审核。

### 巡检中的正常范围为什么没有固定数值

不同设备、介质、工艺和设计条件差异很大。页面示例只帮助理解填写格式，必须使用本企业批准的上下限和设备文件。

### 应急响应颜色可以直接作为启动命令吗

不可以。颜色仅为辅助研判，实际启动权限和报告程序以企业预案、属地规定和现场指挥为准。

### 清洁生产分数能用于正式审核吗

不能。当前权重、目标值和折标参数属于演示模型，正式审核必须采用适用行业标准。

### PID 仿真结果能直接写入控制器吗

不能。该模型用于教学和趋势比较，真实控制器整定需要经过工艺建模、风险分析、联锁核查、仿真验证和受控现场试验。
